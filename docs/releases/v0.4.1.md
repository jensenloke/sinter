# Sinter v0.4.1

Sinter v0.4.1 is a Cloud-free terminal maintenance release. It retains the
public direct-transfer v1 behavior from v0.4.0 while improving updates,
multi-instance workflows, shell-alias discovery, and transcript portability.

## Terminal improvements

- `sinter update --check` performs a side-effect-free registry check.
- `sinter update` installs an exact published version through the detected Bun
  or npm global installation and verifies the resolved executable afterward.
- `sinter config discover-shell` explicitly previews conservative Claude
  `CLAUDE_CONFIG_DIR` aliases without exposing raw alias output or running during
  normal startup, setup, or scans.
- TUI actions qualify exact harness instances, preventing ambiguous resume and
  port targets.
- Codex custom tool input remains readable instead of becoming escaped JSON
  noise when transferred to supported targets.

## Cloud boundary

The public package excludes Sinter Cloud account, device, capsule, hosted
application, Auth0, Supabase, and Storage functionality. Source and built-output
checks reject known Cloud modules, commands, API paths, identity markers, and
hosted URLs before packing or publication.

Sinter Cloud remains on a private development line for maintainer testing.
Repository-bound direct-transfer v2 is also deferred to v0.5.0 because it changes
receiver requirements and is not appropriate for a patch release.

## Release safety

The release candidate remains private and uses a prerelease version until the
complete verification gate and human review pass. Stable publication additionally
requires clean tagged `main`, package/runtime version parity, npm version absence,
and explicit release approval.

The candidate passed 695 tests and 9,047 assertions, TypeScript, production
build, Cloud-free source/dist checks, built-help inspection, package inspection,
isolated Bun/npm installs, and frozen-lockfile verification. Its 23-file tarball
contains only `dist`, package metadata, README, and license.

After stable publication:

```sh
bun add --global @jensenloke/sinter@0.4.1
# or
npm install --global @jensenloke/sinter@0.4.1
```
