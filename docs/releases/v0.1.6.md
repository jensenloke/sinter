# Sinter v0.1.6

Sinter v0.1.6 makes large multi-agent session stores easier to navigate. The TUI now hides Claude team-agent sessions correctly, promotes native titles and local aliases, and makes search and rename actions discoverable.

## Highlights

### Agent sessions are hidden by default

Claude Agent Team workers can be stored as top-level transcript files rather than ordinary sidecar subagents. Earlier Sinter versions treated those files as main sessions, allowing `<teammate-message>` prompts to dominate the TUI.

Sinter now detects bounded native metadata including `teamName`, `agentName`, and teammate prompts. Team-agent sessions are hidden by default alongside other subagents.

The TUI reports how many agent sessions are hidden:

```text
169 agent sessions hidden · ^s show
```

Press `Ctrl+S` to show or hide them.

### Native titles and aliases are visible

Claude's `sessions-index.json` can omit titles written later in a transcript. Sinter now augments indexed rows from bounded head and tail windows, allowing late `ai-title` and `custom-title` records to appear without fully parsing large transcripts.

Title precedence is:

1. Native custom title.
2. Native AI title.
3. Team-agent name.
4. Existing index summary or first prompt.

### Universal Sinter aliases

Every session can receive a Sinter-local alias regardless of harness support:

```sh
sinter rename <id-prefix> "My important session"
```

Clear an alias with:

```sh
sinter rename <id-prefix> --clear
```

Aliases:

- Are stored in Sinter's local ledger, not the source harness.
- Survive rescans and schema upgrades.
- Are searchable from the CLI and TUI.
- Are displayed before the native title.
- Become the target session title when the session is ported.
- Work for live and ghost sessions.

The TUI action screen also includes `set Sinter alias` or `change Sinter alias`.

### Search is easier to discover

The TUI search field now explicitly lists its searchable fields:

```text
search  type now, or ^f · alias, title, prompt, id, path, branch, model…
```

Typing immediately searches the loaded session ledger. `Ctrl+F` clears the current query and focuses the search workflow. The menu load limit has increased from 2,000 to 10,000 rows for larger local stores.

CLI search includes aliases:

```sh
sinter search "success-brain"
```

### Existing ledgers upgrade safely

Ledger schema v3 adds aliases through a separate additive table. Existing session rows, lineage, and FTS data are preserved. Incremental scans now persist corrected subagent classifications even when the native timestamp has not changed.

## Validation

Sinter v0.1.6 passes:

- 509 automated tests.
- Full TypeScript checking.
- Production package build.
- Live Claude scan against 492 sessions.
- Live Expat-Furniture TUI validation, reducing 106 active Claude rows to 17 main sessions with 89 team agents hidden.

## Installation

Run once:

```sh
bunx @jensenloke/sinter@0.1.6
```

Install or upgrade globally:

```sh
bun add --global @jensenloke/sinter@0.1.6
```

After upgrading, refresh the ledger once so corrected Claude titles and agent classifications are applied:

```sh
sinter scan
```
