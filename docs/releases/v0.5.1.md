# Sinter v0.5.1

Status: stable patch release preparation; not tagged or published.

Sinter v0.5.1 fixes compacted Codex sessions that Claude could reject after a
port or encrypted Cloud restore.

## Fix

Some Codex compaction records contain an empty plaintext summary while retaining
the provider-private summary as encrypted content. Sinter previously translated
those boundaries into empty Claude user messages. Claude could later reject the
transcript when resuming it.

The patch now:

- recovers bounded recent user intent only from records explicitly classified as
  `user.text`;
- excludes provider instructions and encrypted compaction blobs from the
  portable summary;
- strips `replacement_history` and provider-private compaction state from compact
  transfer payloads;
- emits a clear portable fallback when no safe summary is available;
- guarantees non-empty historical user and compaction messages in Claude output.

This applies to local ports, direct transfer, and encrypted Cloud sync because
they share the same SIF adapter and compact-transfer path. Cloud protocol,
authentication, quotas, repository binding, and hosted owner-only access are
unchanged.
