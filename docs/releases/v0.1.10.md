# Sinter v0.1.10

Sinter v0.1.10 adds a safe feedback path, a local browser workspace, and consistent transfer modes across the TUI and command line.

## Added

**Send feedback without copying private session data.** `sinter feedback` opens a prefilled GitHub issue containing only the Sinter and Bun versions, OS/architecture, and detected harness names. Paths, session IDs, prompts, and transcripts are excluded. `--no-open` prints the URL instead.

**Browse and move sessions in a local GUI.** `sinter gui` starts a browser workspace with harness filters, search, thread lineage, transcript preview, resume, and port actions. It binds only to `127.0.0.1`, protects data and action endpoints with a random token, blocks external page connections, and never uploads transcripts. `--no-open` leaves browser launching to the user.

**Use transfer modes from scripts.** `sinter port` now accepts `--mode full|slim|compact`, matching the interactive menu. Full keeps the lossless session, slim removes raw provider records, and compact deterministically removes tool noise and thinking while preserving the conversation tree.

**Optional anonymous activity measurement.** `sinter telemetry enable|status|disable` manages an explicit opt-in event stream. It is disabled by default, suppressed in CI and non-interactive commands, contains no session data, and sends nothing unless a collector endpoint is configured.

## Privacy and validation

- Feedback and GUI endpoints have tests preventing raw records, paths, and session identifiers from leaking into diagnostics.
- GUI APIs reject requests without the random access token.
- Full automated test suite and TypeScript checking.
- Production package build, archive inspection, and clean global-install smoke test.

## Installation

Run once:

```sh
bunx @jensenloke/sinter@0.1.10
```

Install or upgrade globally:

```sh
bun add --global @jensenloke/sinter@0.1.10
```
