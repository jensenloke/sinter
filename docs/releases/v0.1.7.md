# Sinter v0.1.7

Sinter v0.1.7 fixes stale interactive processes after their terminal disappears.

## Fixed

The interactive menu now treats stdin EOF, stream closure, and stream errors as terminal disconnects. It exits through the normal quit path, restores terminal state, and removes its listeners instead of remaining alive beneath an orphaned shell.

Zero-length input is handled as EOF as well, preventing a detached terminal from driving a continuous repaint loop and consuming a CPU core.

## Validation

- Terminal-disconnect smoke test through a real pseudo-terminal.
- Full automated test suite.
- Full TypeScript checking.
- Production npm package build and archive inspection.

## Installation

Run once:

```sh
bunx @jensenloke/sinter@0.1.7
```

Install or upgrade globally:

```sh
bun add --global @jensenloke/sinter@0.1.7
```
